AI Assistant Settings

The built-in assistant works immediately with no setup: it reads the selected patient's scores and questionnaire results from this app's own data and generates routines and answers using deterministic logic, entirely in your browser.

Backend Server is the recommended way to use a real AI model: run the FastAPI server in this repo's backend/ folder with your OpenAI key in its .env file, then point this app at it. Your key never leaves the server or touches this browser.

The direct-from-browser Claude/OpenAI options store your key in this browser's local storage and send it straight to the provider's API — convenient for quick testing, but the key is exposed in your browser and requests can fail due to the provider's CORS policy. Either way, if the call fails the assistant automatically falls back to the built-in engine.
